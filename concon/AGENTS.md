# ConCon working rules

## Core doctrine

- Proposal is not agreement.
- Inference is not confirmation.
- Exploration is not decision.
- Memory is not truth.
- Nothing consequential silently merges into shared state.
- Conversation is evidence; derived shared state must remain traceable to evidence.

## Current scope

This repository begins as an architecture-first prototype.

Do not:
- add a backend,
- add accounts,
- add telemetry or analytics,
- add payments or licensing,
- introduce an external AI API without explicitly stopping for review,
- build the full congruence/receipt engine yet.

The first goal is only to make a live ChatGPT conversation organize itself into a useful chronological living outline in a right-side browser-extension panel.

Before significant coding, inspect the target environment and propose the smallest robust architecture.
