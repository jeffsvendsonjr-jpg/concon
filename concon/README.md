# ConCon

**Conversational Congruence**

ConCon is an experimental tool for making the evolving structure of long AI conversations visible, navigable, and eventually auditable for shared-state drift.

## Current milestone

Make the invisible conversation structure visible.

The first prototype should:
- observe one live ChatGPT conversation,
- build a chronological living outline of meaningful topic transitions,
- let the user click a topic to jump back to the source conversation,
- support simple literal/topic search,
- keep derived interpretation separate from user-confirmed state.

No congruence enforcement yet. No backend. No accounts. No telemetry.
